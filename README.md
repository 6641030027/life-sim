# life-sim

เกมจำลองชีวิตบนเว็บ (ต้นแบบ UI) เปิดเล่นที่ https://6641030027.github.io/life-sim/

## โครงสร้างไฟล์

```
index.html            โครงหน้าเว็บ (HTML ล้วน)
css/style.css         หน้าตาทั้งหมด
js/main.js            จุดเริ่มต้น ผูกปุ่มกับฟังก์ชัน
js/game.js            ลำดับการเล่น: เริ่มชีวิตใหม่, กดข้ามปี
js/state.js           สถานะเกมที่เปลี่ยนระหว่างเล่น
js/util.js            ตัวช่วยทั่วไป
js/data/              ข้อมูลล้วน (แก้ได้โดยไม่แตะระบบ)
  names.js            ชื่อ นามสกุล อาชีพ ชื่อสัตว์เลี้ยง ประเทศ
  stages.js           ช่วงวัย และจุดเน้นของปีแต่ละช่วงวัย
  stats.js            แถบสถานะ
  skills.js           ทักษะ
  events/             เหตุการณ์แยกตามช่วงวัย 7 ช่วง (ทารก/หัดเดิน/เด็ก/รุ่น/หนุ่มสาว/ผู้ใหญ่/ผู้สูงอายุ) (index.js เลือกเหตุการณ์ตามอายุ)
js/engine/character.js  สุ่มตัวละครและครอบครัวตอนเกิด
js/engine/family.js    สุ่มครอบครัวต้นกำเนิด 6 แบบพร้อมเรื่องราวตอนเกิด (ข้อมูลใน data/families.js)
js/engine/friends.js    เพื่อนร่วมชั้น (สร้างตอนเข้า ป.1) และคำนวณค่าสังคม
js/engine/growth.js     วัยทารก/หัดเดิน/เด็ก: สุ่มสิ่งที่เด็กทำจริงแต่ละปี สิ่งที่เลือกเพิ่มโอกาสตามอายุ ให้โบนัสลับเล็กๆ กับทักษะ (ข้อมูลใน data/activities.js)
                        (พ่อแม่มียีนซ่อน ลูกสืบทอดครึ่งหนึ่ง เก็บที่ me.genes เพื่อเล่นเป็นลูกต่อในอนาคต)
js/engine/appearance.js สุ่มรูปลักษณ์ โดยหยิบชิ้นส่วนจากคลัง
  data/parts/         คลังชิ้นส่วนตัวละคร (skin, hair, tops, bottoms) เติมแถวเพื่อเพิ่มแบบใหม่
js/ui/                หน้าจอแต่ละส่วน (บันทึก, สถานะ, จุดเน้น, ป็อปอัป, ความสัมพันธ์, ทักษะ, ตั้งค่า)
```

## หมายเหตุ

- ใช้ ES modules ธรรมดา ไม่มีขั้นตอน build เปิดผ่านลิงก์เว็บเท่านั้น (เปิดไฟล์ตรงจากเครื่องไม่ได้)
- ทุก `import` ต้องมีนามสกุล `.js`

## เพิ่มเหตุการณ์ใหม่

เหตุการณ์ที่ใช้ได้เฉพาะบางประเทศ ใส่ `country: ['ไทย']` ในเหตุการณ์นั้น (ดูจากประเทศที่ "อาศัยอยู่" ตอนนี้ `me.residence` ไม่ใช่ที่เกิด ไม่ใส่ = ทุกประเทศ) หรือ `born: ['ไทย']` ถ้าดูจากประเทศที่เกิด ส่วนเหตุการณ์จากทักษะแยกไว้ใน `skill-events.js` และยังไม่เปิดใช้ (รอทำระบบอาชีพ)

เปิดไฟล์ของช่วงวัยนั้นใน `js/data/events/` แล้วเพิ่มรายการใน `EVENTS` ตามรูปแบบที่อธิบายไว้หัวไฟล์ `js/engine/events.js`
ไม่ต้องแก้ระบบ ใส่ `family` / `sub` / `reason` ถ้าเป็นเรื่องเฉพาะต้นกำเนิด ไม่ใส่ถ้าเกิดได้กับทุกคน

### เหตุการณ์ผู้ใหญ่ที่แยกไว้ (ซ่อน)
`js/data/events/intimacy.js` เป็นเหตุการณ์ความใกล้ชิดของคู่รัก เงื่อนไขอายุ 18 ปีขึ้นไปทั้งผู้เล่นและแฟน ถูก import ผ่าน young.js (เปิดใช้แล้ว) ดูวิธีเปิดใช้และสูตรโอกาสที่หัวไฟล์
